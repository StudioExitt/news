클립아트코리아해외부동산 공모펀드를 비교적 안전한 투자처로 생각했다가 원금을 모두 잃거나 배당금을 제때 받지 못하는 사례가 이어지자 금융당국이투자자들에게 주의를 당부했다.금융감독원은10일“부동산 펀드 원금 전액 손실 사례와관련 분쟁 민원이꾸준히 접수되고있다”며해외부동산펀드투자시유의해야할사항을안내했다.금감원은투자대상이부동산이라는이유만으로해당상품을안전하다고판단해서는안다고강조했다.해외부동산펀드는현지부동산을매입하는과정에서금융기관대출을활용하는레버리지구조가일반적이다.이에따라부동산가치가크게떨어지지않더라도손실폭이확대돼투자원금전액을잃할가능성이있다.부동산가격하락등으로대출약정상조건을충족하지못할 경우대출기관이담보권을행사해건물을강제매각할수도있다.이때매각대금은대출금을갚는데먼저사용되고,남은금액만펀드투자자에게돌아간다।배당이중단되는상황도발생할수있다.임대수익이투자자에게지급되지않고대출기관에우선귀속되는이른바‘캐시트랩’조항이적용될수있기때문이다.캐시트랩은담보인정비율(LTV)이일정기준을넘거나공실률이상승하는등특정조건이발생했을때작동한다.이경우펀드에서임대수익이발생하더라도투자자에게배당되지않을수있다.투자금을원하는시점에되찾기어렵다는점도주의해야한다.해외부동산펀드는만기이전에투자금을돌려받기어려운환매금지형으로운용되는경우가많다.일부펀드는거래소에상장돼있더라도거래량이적으면실제매매가쉽지않을수있다.투자금을급히회수하려면펀드가보유한자산가치보다낮은가격에팔아야하는상황도생길수있다.만기가돌아온뒤에도곧바로투자금을돌려받는다는보장은없다.해외부동산매각과펀드청산절차가길어질경우실제자금회수시점이예상보다늦춰질수있다.수익자총회에서만기연장에반대하고투자금반환을요구해도지급할재원이충분하지면회수가지연될가능성이있다.만기가연장되는동안공실률이높아지거나임대수익이줄고부동산가격까지하락할경우기존손실이더커질수있다.펀드가입당시판매사의설명을충분히들었는지도확인할필요가있다.청약신청서에‘설명을듣고이해했음’이라고직접작성한경우향후설명의무위반을이유로판매사에배상을요구하더라도책임이인정되기어려울수있다.금감원은투자자가자신의투자가능기간과감당할수있는손실수준등을충분고려한뒤상품가입여부를결정해야한다고당부했다.금감원관계자는“앞으로도금융투자상품관련분쟁사례및투자자유의사항을적시에안내할계획”이라며“필요할경우제도개선을통해투자자보호를강화해나가겠다”고말했다.
