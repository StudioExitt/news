【 앵커멘트 】 로또 당첨 금액이 크지 않다면 무심코 세탁기에 넣어 돌리거나 당첨금 찾는 걸 1년 넘게 깜빡하는 경우가 적지 않습니다. 지금까지는 모두 당첨금 수령이 어려웠는데, 앞으로는 앱에 복권을 등록만 하면 자동으로 입금됩니다. 이혁근 기자입니다. 【 기자 】 서울 노원구의 한 로또 판매점. 대박을 기원하며 긴 줄이 섰습니다. 그런데 행운이 찾아와도 뜻밖의 부주의로 놓치는 경우가 적지 않습니다. ▶ 인터뷰 : 최영길 / 로또 구매 시민 - "5천 원짜리 하나 되면 나중에 다음 주에 바꿔야지 그러고 놨다가 그냥 안 된 줄 알고 버리게 되는 경우도 있고…." ▶ 스탠딩 : 이혁근 / 기자 - "로또 당첨금은 지급 시작일부터 1년 안에 찾아야 합니다. 종이 복권을 잃어버리거나 깜빡 잊어서 찾지 못한 당첨금은 지난해 581억 원에 달합니다." 5만 원이나 5천 원에 당첨된 경우가 대부분이지만 당첨금 수령 권리가 사라진다는 지적이 나오는데, 다음 주 화요일부터는 달라집니다. 종이 로또를 간편결제 앱, 페이코에 등록만 해놓으면 1년 뒤에 당첨금을 자동으로 입금해주는 겁니다. 구매 직후 등록만 해놓으면 세탁물에 섞여 로또 종이가 훼손돼도 당첨금 수령이 가능합니다. 다만, 등록했다고 종이 복권을 버리는 건 위험합니다. ▶ 인터뷰 : 오은실 / 기획예산처 복권위원회 사무처장 - "지급 기한 전날까지 실물 복권을 가진 분이 판매점이나 은행에서 우선 수령할 수 있기 때문에 실물을 잃어버리시면 제3자가 돈을 받아갈 위험이…." 복권위원회는 또 모레(13일)부터 1만 개에 가까운 로또 판매점의 실시간 영업 정보를 네이버지도와 카카오맵에 제공하겠다고 밝혔습니다.
