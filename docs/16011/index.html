코스피 지수가 개장 초 상승세를 보였으나, 기관과 개인의 대규모 차익 실현 물량에 하락세로 전환하며 7000선 아래로 급락했다. 외국인이 매수했음에도 불구하고 투자자들의 순매도 압력이 강하게 작용하며 지수를 끌어내렸다.
