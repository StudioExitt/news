정정한 증권신고서를 바탕으로 수요예측을 이어가요. 레몬헬스케어 코스닥 상장…증거금 5조 모인 레메디 6일 환불 레몬헬스케어는 오는 6일 코스닥 시장에 상장해요. 레몬헬스케어는 의료 마이데이터 중개 플랫폼을 주력으로 하는 디지털 헬스케어 기업이에요. 병원과 환자 사이에서 진료 정보와 의료 데이터를 연결하는 플랫폼 사업을 하고 있어요. 앞서 레몬헬스케어는 기관투자자 수요예측에서 공모가를 희망 범위 상단인 1만원으로 확정했어요. 수요예측에는 기관투자자 2233곳이 참여했고 경쟁률은 1238대 1로 집계됐어요. 참여 기관의 약 99%가 희망범위 상단 이상 가격을 제시했어요. 일반 청약에서도 투자 수요가 몰렸어요. 증권발행실적보고서에 따르면 일반투자자 배정 물량 50만주에 7억5528만4210주가 접수됐어요. 솔루션 전문 기업이에요. 의료진이 장비를 직접 들고 촬영할 수 있도록 크기와 무게를 줄인 휴대용 엑스레이 장비를 개발해요. 주력 제품은 의료용 휴대용 엑스레이 장비 'KA6'인데요. 2.4㎏ 무게에 전원을 켠 뒤 5초 안에 촬영을 준비할 수 있고 한 차례 충전하면 270회에서 290회까지 촬영할 수 있다고 해요. 정정신고서 낸 에이치엘지노믹스, 수요예측
